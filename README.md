# حكاية

تطبيق بسيط ودافئ لكتّاب القصص والمحتوى المقروء.

## التشغيل
افتح الملف `index.html` في المتصفح. لا يحتاج تثبيت ولا إنترنت (الخطوط فقط تُحمّل من Google Fonts وإن لم تتوفر تُستخدم خطوط النظام).

## المميزات
- كتابة وحفظ تلقائي في المتصفح (localStorage)
- قائمة قصص، وعدّاد كلمات ووقت القراءة، وهدف كلمات
- "أعطني فكرة" لشرارة بداية
- وضع التركيز، وتصدير القصة كملف نصي

## التعديل
- الألوان في أعلى `style.css` (المتغيرات داخل :root)
- الأفكار الجاهزة في أعلى `app.js` (المصفوفة ideas)
